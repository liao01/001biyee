# Triage labels

工程技能使用五种标准分流角色。下表定义它们在当前 GitHub 仓库中的实际标签。

| 标准角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已明确，可交给代理 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 决定不处理 |

技能提及标准角色时，应使用表中对应的 GitHub 标签。
